# Приложение оценки эффективности сотрудников — лабораторная работа №1

REST API для управления оценкой эффективности сотрудников (Employee Performance Evaluation).

## Цель работы

Приобретение практических навыков создания серверного приложения на платформе Node.js
с использованием фреймворка Express.js: маршрутизация, обработка HTTP-запросов
(GET, POST, PUT, DELETE) и формирование ответов сервера.

## Предметная область

Приложение предназначено для оценки эффективности работы сотрудников. Каждый сотрудник имеет:

- **id** — уникальный идентификатор
- **name** — ФИО сотрудника
- **position** — должность
- **department** — отдел
- **rating** — оценка эффективности (число от 1 до 10)
- **reviewDate** — дата проведения оценки (строка в формате YYYY-MM-DD)

Данные временно хранятся в массиве в памяти сервера и сбрасываются при перезапуске.

## Технологии

- Node.js
- Express.js
- Nodemon (для разработки)

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки (nodemon, авто-перезапуск)
npm run dev

# Обычный запуск
npm start
```

Сервер запускается на порту **3000**.

## API

Базовый URL: `http://localhost:3000/api/v1`

Ресурс: `/employees`

| Метод  | Эндпоинт                | Описание                            |
|--------|--------------------------|-------------------------------------|
| GET    | `/api/v1/employees`      | Получить список всех сотрудников    |
| GET    | `/api/v1/employees/:id`  | Получить сотрудника по ID           |
| POST   | `/api/v1/employees`      | Добавить нового сотрудника          |
| PUT    | `/api/v1/employees/:id`  | Полностью обновить данные сотрудника|
| DELETE | `/api/v1/employees/:id`  | Удалить сотрудника                  |

### Пример тела запроса (POST / PUT)

```json
{
  "name": "Иван Иванов",
  "position": "Разработчик",
  "department": "IT",
  "rating": 8.5,
  "reviewDate": "2026-09-01"
}
```

### Коды ответов

| Код | Описание                            |
|-----|-------------------------------------|
| 200 | Успешный запрос                    |
| 201 | Сотрудник успешно создан           |
| 400 | Некорректные данные запроса        |
| 404 | Сотрудник с указанным ID не найден |
| 500 | Внутренняя ошибка сервера          |

## Структура проекта

Проект построен по слоистой архитектуре:

```
my-node-app/
├── app/
│   └── api/v1/
│       ├── employees.js    # Маршруты сотрудников (CRUD)
│       └── router.js       # Объединение маршрутов v1
├── core/
│   ├── config.js           # Конфигурация (порт)
│   ├── AppError.js         # Класс ошибок приложения
│   └── errorHandler.js     # Глобальный обработчик ошибок
├── repositories/
│   └── employeeRepository.js  # Работа с данными (массив в памяти)
├── schemas/
│   └── employeeSchema.js   # Валидация данных сотрудника
├── services/
│   └── employeeService.js  # Бизнес-логика
├── server.js               # Точка входа
└── package.json
```

## Слои и их ответственность

| Слой             | Ответственность                          |
|------------------|------------------------------------------|
| `app/api/v1`     | HTTP-маршруты, обработка запросов        |
| `services`       | Бизнес-логика, валидация, вызовы репо   |
| `repositories`   | Доступ к данным (массив в памяти)        |
| `schemas`        | Валидация входных данных                 |
| `core`           | Конфигурация, ошибки, обработчики        |
