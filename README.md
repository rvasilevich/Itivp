# Itivp — Приложение оценки эффективности сотрудников

REST API для управления оценкой эффективности сотрудников (Employee Performance Evaluation) и клиентское React-приложение.

## Стек

- **Backend:** Node.js, Express.js, Sequelize (ORM), PostgreSQL
- **Frontend:** React 19 + Vite, axios
- **Прочее:** JWT, bcrypt, Nodemon

## Структура репозитория

```
main ────────────── только документация (README и т.п.)
 └─ develop ─────── интеграционная ветка, сюда вливаются лабораторные ветки
     ├─ lab21 ───── Лабораторная работа №1 — Express REST API (CRUD, данные в памяти)
     ├─ lab22 ───── Лабораторная работа №2 — PostgreSQL + Sequelize (модели, миграции, сиды)
     ├─ lab23 ───── Лабораторная работа №3 — ...
     ├─ lab24 ───── Лабораторная работа №4 — ...
     └─ lab25 ───── Лабораторная работа №5 — ...
release ─────────── финальная версия проекта со всеми заданиями
```

Каждая лабораторная работа выполняется в отдельной ветке от `develop` и вливается
обратно в `develop`. Готовый проект собирается в ветке `release`.

Подробности по запуску и локальной разработке — в `RUNBOOK.md` в ветках с кодом.
